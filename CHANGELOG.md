# Changelog

## 0.1.0 — 2026-10-19

Initial trusted-input v0 release candidate:

- deterministic offline mock-provider workflow;
- validated task graphs and dependency cycles;
- temporary workspace execution with verified-file synchronization;
- AST, targeted-test and regression gates;
- bounded retries and execution reports;
- OpenAI-compatible local provider with timeout handling;
- hardware-aware llama.cpp and MLX launch policy;
- package console commands: `cdavc` and `cdavc-launch`;
- Docker, CI, contributor, security and license documentation.

Known limitations are documented in `README.md`, `SECURITY.md` and `docs/`.
