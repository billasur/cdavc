The plot

One model. Four gates. No vibes.

The cloud can draft the plan. The local model can draft the patch. Only deterministic checks can advance the task.

01 / contract

Define the surface

Task IDs, symbols, invariants, dependencies and an existing test manifest become a constrained job.

02 / write

Fresh local context

A cached instruct or coder model returns a patch for implementation files—never a free-form edit session.

03 / verify

Run the cage

AST, targeted tests and regression tests execute in a temporary workspace with bounded retries.

04 / report

Advance or repair

A pass synchronizes verified files. A failure returns a small trace to the next attempt and stops when the budget ends.
