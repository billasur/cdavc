# Contributing

1. Use Python 3.11 or 3.12.
2. Keep runtime dependencies minimal and update the lockfile when adding one.
3. Write a failing test before production behavior changes.
4. Run `make test` before committing.
5. Do not commit model weights, credentials, `.env` files or local caches.
6. Keep public documentation honest about trusted-input and runtime limitations.

Use conventional commit messages such as `feat:`, `fix:`, `test:`, `docs:` and
`chore:`.
